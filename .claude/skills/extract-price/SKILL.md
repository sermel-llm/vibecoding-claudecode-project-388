# Extract price

## Вход
URL страницы одного товара, на которой указана цена.

## Выход
Ровно один JSON-объект без пояснений до или после, со следующими полями:

```json
{"regular_price": 12990, "sale_price": 9990, "has_credit": true}
```

- `regular_price` — обычная цена без скидки, число.
- `sale_price` — цена со скидкой, число; `null`, если скидки нет.
- `has_credit` — `true`, если на странице есть рассрочка или кредит; иначе `false`.

Используй только прямые двойные кавычки `"`

## Шаги
1. Загрузи страницу по URL на входе.
2. Найди цену. Для известных сайтов сначала смотри источник из подсказки:
   1. nix.ru — элемент с классом `price pc-component-non-used pc-component-inactive`.
   2. regard.ru — JSON-LD (`Product` → `offers.price`). Рассрочка на сайте есть: блок `installment` («Рассрочка», «Оплата частями») в данных страницы означает `has_credit: true`.
   3. oldi.ru, xcom-shop.ru — `itemprop="price"`.
   4. kns.ru — `itemprop="price"` содержит цену со скидкой; обычная цена указана только в тексте страницы рядом со значком скидки (например, «1,02%»). Проверяй обе.
   5. dns-shop.ru — класс `product-buy__price`. При обычной загрузке сайт блокирует доступ (Qrator); подсказка для работы через браузер.
   6. onlinetrade.ru — класс `js__actualPrice`. При обычной загрузке сайт показывает капчу; подсказка для работы через браузер.
   Для остальных сайтов проверяй по порядку:
   7. Разметка JSON-LD (`<script type="application/ld+json">`, тип `Product` → `offers`).
   8. Мета-теги: `product:price:amount`, `og:price:amount`, `itemprop="price"`.
   9. Видимый текст рядом с кнопкой «В корзину» / «Купить».
3. Определи цены:
   - Если на странице две цены (одна зачёркнута) — зачёркнутая это `regular_price`, другая — `sale_price`.
   - Если цена одна — это `regular_price`, а `sale_price` = `null`.
   - Бери цену основного товара, а не аксессуаров, похожих товаров или блоков «С этим покупают».
   - Не считай скидкой цены по карте лояльности, промокоду или «при оплате онлайн».
   - Цена в разметке может быть уже со скидкой. Всегда проверяй видимый текст рядом на зачёркнутую или вторую цену.
4. Определи `has_credit`: ищи «рассрочка», «в кредит», «оплата частями», «Сплит», «Долями», «×N платежей», «от N ₽/мес». Нашёл — `true`, иначе `false`.

## Формат чисел
- Только число, без валюты и пробелов: «12 990 ₽» → `12990`.
- Копейки — через точку: «1 299,50» → `1299.5`.

## Если не получилось
- Страница не загрузилась или цена не найдена — верни:
  `{"error": "краткая причина"}`
- Не придумывай цену. Лучше ошибка, чем неверное число.
