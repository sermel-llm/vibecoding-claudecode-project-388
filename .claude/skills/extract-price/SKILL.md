# Extract price

## Вход
URL страницы одного товара, на которой указана цена.

## Выход
Ровно один JSON-объект без пояснений до или после, со следующими полями:

```json
{"regular_price": 12990, "sale_price": 9990, "has_credit": true}
```

- `regular_price` — обычная цена без скидки, число.
- `sale_price` — цена со скидкой, число; `null`, если скидки нет.
- `has_credit` — `true`, если на странице есть рассрочка или кредит; иначе `false`.

## Шаги
1. Загрузи страницу по URL на входе.
2. Найди цену:
   1. Для сайта nix.ru — элемент с классом `price pc-component-non-used pc-component-inactive`.
   2. Для сайта dns-shop.ru - элемент с классом `product-buy__price`.
   3. Для сайта onlinetrade.ru - элемент с классом `js__actualPrice`.
   4. Разметка JSON-LD (`<script type="application/ld+json">`, тип `Product` → `offers`).
   5. Мета-теги: `product:price:amount`, `og:price:amount`, `itemprop="price"`.
   6. Видимый текст рядом с кнопкой «В корзину» / «Купить».
3. Определи цены:
   - Если на странице две цены (одна зачёркнута) — зачёркнутая это `regular_price`, другая — `sale_price`.
   - Если цена одна — это `regular_price`, а `sale_price` = `null`.
   - Бери цену основного товара, а не аксессуаров, похожих товаров или блоков «С этим покупают».
   - Не считай скидкой цены по карте лояльности, промокоду или «при оплате онлайн».
4. Определи `has_credit`: ищи «рассрочка», «в кредит», «оплата частями», «Сплит», «Долями», «×N платежей», «от N ₽/мес». Нашёл — `true`, иначе `false`.

## Формат чисел
- Только число, без валюты и пробелов: «12 990 ₽» → `12990`.
- Копейки — через точку: «1 299,50» → `1299.5`.

## Если не получилось
- Страница не загрузилась или цена не найдена — верни:
  `{"error": "краткая причина"}`
- Не придумывай цену. Лучше ошибка, чем неверное число.
